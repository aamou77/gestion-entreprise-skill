# Briques tierces envisagées

Le projet pourra s’appuyer sur des briques tierces auditées, notamment
Open Accountant. Cette mention constitue une piste à examiner, pas un audit
réalisé ni une décision d’intégration.

Aucun code ou contenu tiers n’est actuellement embarqué.
Avant toute intégration, identifier la provenance et la version, auditer la
brique et sa licence, puis tracer les éléments retenus et les modifications
éventuelles dans `../NOTICE.md`.
