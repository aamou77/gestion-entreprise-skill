# gestion-entreprise-skill

Squelette initial d’un projet de skills de gestion d’entreprise.

- `SKILL.md` : point d’entrée.
- `skills/` : emplacements des cinq domaines prévus.
- `references/france/` : fiches de référence à compléter et à vérifier.
- `adapters/livre_des_recettes/` : emplacement d’une future intégration externe.
- `upstream/` : suivi des briques tierces envisagées.
- `tests/` : emplacement des futurs tests.
- `NOTICE.md` : registre des futurs composants tiers.
- Licence : MIT.

Aucune fonctionnalité, dépendance, intégration ou moteur de calcul n’est présent.
Aucune règle métier, fiscale, sociale ou réglementaire n’est définie.
Aucune logique CRM ou comptable n’est implémentée.
Aucun contenu ni code de projet tiers n’est embarqué.
